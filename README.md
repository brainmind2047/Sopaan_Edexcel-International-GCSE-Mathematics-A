# International GCSE Mathematics A

Learning sheets for all 33 chapters, mixing Collins International GCSE Maths for Edexcel (Book 1) with Pearson Edexcel International GCSE (9–1) Mathematics A Student Book 2 by topic. Each learning objective has a learning sheet, Collins practice, Pearson practice where Book 2 covers it, and a 30-minute test.

- `index.html` — home page linking all 33 chapters
- one self-contained HTML page per chapter

## Publish with GitHub Pages
1. Upload every file in this folder to the root of a repository.
2. Settings → Pages → Deploy from a branch → `main`, `/ (root)` → Save.
3. The site goes live at `https://<username>.github.io/<repository>/` after a minute.

Each student's progress is saved in their own browser; sign in with the same name, roll number and PIN each time.
